# Font situs

`newsreader-latin.woff2` dan `plus-jakarta-sans-latin.woff2` adalah subset Latin dari font yang sebelumnya dimuat melalui `next/font/google`. Keduanya disimpan lokal agar pengembangan dan build tidak memerlukan akses jaringan ke Google Fonts.

- Newsreader: https://github.com/google/fonts/tree/main/ofl/newsreader — lisensi di `NEWSREADER-OFL.txt`.
- Plus Jakarta Sans: https://github.com/google/fonts/tree/main/ofl/plusjakartasans — lisensi di `PLUS-JAKARTA-SANS-OFL.txt`.
